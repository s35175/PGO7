\# Membership Plan System



\## Project Overview



This project is a Java object-oriented programming project prepared for the PGO course.



The application represents a simple membership plan management system. It includes different types of membership plans and calculates their monthly net price, monthly gross price, and total net price for the full contract period.



The project demonstrates important object-oriented programming concepts such as abstract classes, interfaces, inheritance, method overriding, polymorphism, encapsulation, arrays of objects, and the instanceof operator.



\---



\## Main Features



\- Create different types of membership plans

\- Calculate monthly net price

\- Calculate monthly gross price with VAT

\- Calculate total net price for the whole contract period

\- Display summary information for each plan

\- Check whether a plan can be frozen

\- Check whether a plan provides online access

\- Use polymorphism to process different plan types in one array



\---



\## Object-Oriented Programming Concepts Used



\- Abstract class

\- Interface

\- Inheritance

\- Method overriding

\- Polymorphism

\- Encapsulation

\- Array of objects

\- instanceof operator
